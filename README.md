# Рентабельность сделки

Интерактивный одностраничный калькулятор для анализа рентабельности проекта, структуры расходов, прибыли и сценариев «что, если».

Рабочая версия: [https://rentsdelki.точкаростамск.рф](https://rentsdelki.точкаростамск.рф)

## Запуск

Откройте `index.html` в браузере. Для работы диаграмм и оформления требуется подключение к интернету, поскольку Tailwind CSS, Chart.js и шрифты загружаются с CDN.
